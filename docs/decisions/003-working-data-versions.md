# ADR-003: рабочие версии исходных данных

Дата: 2026-08-21

Статус: принято

## Контекст

Методист вводит исходные данные поэтапно. Требование полной готовности при
каждой активации мешает сохранять согласованный промежуточный результат, а
разные правила Excel и ручного режима делают поведение системы непредсказуемым.

## Решение

Excel, ручной ввод, CLI и API используют единый валидатор инвариантов.
Активация всегда блокируется при дублях, битых ссылках, несовместимой области
замены и других структурных противоречиях.

Структурно корректный, но неполный набор разрешено активировать как рабочую
версию. После активации детерминированный отчёт готовности перечисляет причины,
по которым решатель недоступен. Запуск расчёта разрешается только для готового
набора.

## Последствия

- Методист может безопасно сохранять промежуточные этапы подготовки данных.
- Все входы отклоняют одинаковые противоречия с одинаковыми стабильными кодами.
- Понятия «активная версия» и «готовая к расчёту версия» различаются в API и UI.
- Любая будущая точка активации обязана вызывать общий валидатор, а не создавать
  собственный набор правил.
