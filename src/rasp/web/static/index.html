Как подготовить исходные данные?

Выберите удобный способ. Оба режима создают локальную версию данных.

Исходные данные

Импорт исходных данных

Загрузите один файл с листами «Преподаватели», «Группы», «Нагрузка», «Специальности», «Учебные планы», «Дисциплины», «Студенты», справочниками помещений, учебными годами, периодами, сеткой звонков, исключениями календаря и недоступностью ресурсов. Проверка не изменяет активную версию данных.

Локальная обработка

Файл проверяется на этом компьютере. Значения ячеек не записываются в журнал ошибок.
