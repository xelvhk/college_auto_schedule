# College Timetable

[![CI](https://github.com/xelvhk/college_auto_schedule/actions/workflows/ci.yml/badge.svg)](https://github.com/xelvhk/college_auto_schedule/actions/workflows/ci.yml)

Локальная система подготовки и составления расписания колледжа. Текущая итерация реализует безопасный импорт и версионированное локальное хранилище; генератор расписания находится в следующих этапах [roadmap](docs/roadmap.md).

Целевая поставка — устанавливаемое приложение для Windows 10/11 x64, работающее без отдельной установки Python. Установщик еще не выпущен: текущее состояние запускается из исходного кода. Архитектура поставки описана в [ADR-001](docs/decisions/001-windows-distribution.md).

## Что уже работает

- строгая доменная модель преподавателей, групп и учебной нагрузки;
- единый файл `.xlsx` с листами `Преподаватели`, `Группы`, `Нагрузка`;
- проверка обязательных колонок, значений, дубликатов и ссылок нагрузки;
- отклонение формул, макросов, внешних ссылок, вложенных объектов и подозрительных ZIP-контейнеров;
- атомарный результат: возвращается весь валидный пакет или только протокол ошибок, без частичных данных.
- транзакционная запись в SQLite с внешними ключами и единственной активной версией;
- идемпотентный повторный импорт по SHA-256;
- просмотр истории и возврат к ранее сохраненной версии.

Полный контракт будущего импорта специальностей, учебных планов, дисциплин и студентов находится в [спецификации справочных данных](docs/specs/reference-data-imports.md).

## Локальный запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -e .
rasp validate path/to/import.xlsx
rasp import path/to/import.xlsx --database data/rasp.sqlite3
rasp status --database data/rasp.sqlite3
rasp activate-version 1 --database data/rasp.sqlite3
```

### Веб-интерфейс

```bash
.venv/bin/uvicorn rasp.web.app:app --host 127.0.0.1 --port 8000
```

После запуска откройте `http://127.0.0.1:8000`. Интерфейс сначала выполняет предпросмотр без записи в базу, а кнопка «Активировать версию» повторно проверяет файл и только затем меняет активные данные. Путь к SQLite можно задать переменной `RASP_DATABASE_PATH`; по умолчанию используется `data/rasp.sqlite3`.

Без установки пакета:

```bash
PYTHONPATH=src python3 -m rasp.cli validate path/to/import.xlsx
```

Успешная операция возвращает код `0`. Ошибка Excel-валидации возвращает код `2`, ошибка хранилища — `3`, неизвестная версия — `4`. Все ответы выдаются в JSON; в протокол импорта не включаются значения ячеек и полный путь к исходному файлу.

Импорт сначала полностью проверяет неизменившийся файл, а затем в одной транзакции сохраняет преподавателей, группы и нагрузку. При ошибке новая версия откатывается, а предыдущая остается активной. Повторный импорт того же содержимого не создает копию данных.

Веб-сервер предназначен для локального запуска на loopback-адресе. Мутации с внешним `Origin` отклоняются; ответы защищены CSP, `X-Frame-Options`, `nosniff` и запретом кеширования. Для публикации в сети потребуется отдельный этап аутентификации, HTTPS и настройки доверенного прокси.

## Тесты

```bash
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

Все примеры синтетические. Реальные выгрузки колледжа следует хранить вне репозитория в каталоге `data/` или `imports/`.

GitHub Actions выполняет этот набор тестов на Linux и Windows с Python 3.12, проверяет согласованность зависимостей и собирает wheel со статическими ресурсами. Windows installer будет добавлен отдельным release workflow после реализации desktop launcher.
